

__파일 디스크럽터 (File Descriptor)__
  + 운영체제가 접근하는 파일, 소켓, 파이프 등 입출력 리소스를 구분하기 위해 부여하는 정수
  + 프로세스가 시작되면 기본적으로 3개의 FD가 장동 실행
    + 0 : stdin - 표준 입력
    + 1 : stdout - 표준 출력
    + 2 : stderr - 표준 에러
  + pipe()를 호출해 파이프 생성 시 비어 있는 FD를 할당함


---
__프로세스의 FD__
+ 각 프로세스는 고유 FD 테이블을 가진다

---
__부모-자식 간 파이프 공유__
+ 파이프는 커널의 메모리 공간에 생성
+ 순서 => 부모-자식은 각자의 FD를 가지지만, 파이프는 같은 커널 버퍼에 저장됨
  + pipe() 호출 : 리눅스 커널에 파이프 생성
  + 커널은 부모 프로세스에 파이프에 쓰고, 읽을 수 있는 파일 디스크럽터 부여
  + fork() 호출 : 자식 프로세스에 같은 FD 공유
 
---
__사용하지 않는 파이프 FD 닫기__
+ 데이터를 읽는 파이프가 쓰기 FD를 닫지 않으면 커널은 아직 파이프에 작성 중이라 인식
+ 사용하지 않는 FD는 close()로 닫아야 함

---
__부모-자식 프로세스__
+ 부모 프로세스는 wait(Null)로 자식 프로세스가 종료될 때까지 대기함
+ 자식 프로세스는 exit()를 호출 -> 커널이 부모 프로세스에세 시그널 송신
+ 부모 프로세스가 자식 프로세스보다 먼저 종료되어 좀비 프로세스가 됨을 방지
